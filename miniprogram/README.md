# 基金分析器 · 微信小程序

这是“基金分析器”H5 网页的微信小程序壳工程（使用 `web-view` 组件直接加载网页，功能与 H5 完全一致）。

## 使用步骤

1. **把网页部署到 HTTPS 域名**
   把项目里的 `index.html`、`app.js`、`style.css`、`funds.js`、`manifest.json`、`icon-*.png`、`vendor/` 上传到任意 HTTPS 静态托管（如 Gitee Pages、GitHub Pages），得到一个网页链接。

2. **填写网页地址**
   修改本目录 `config.js` 里的 `WEB_URL` 为你的网页链接。

3. **注册小程序并配置业务域名**
   - 在微信公众平台注册小程序（**企业 / 个体户主体**才能使用 `web-view`，个人主体不支持）；
   - 进入「开发管理 → 开发设置 → 业务域名」，把网页域名添加进去并下载校验文件放到网站根目录完成校验。

4. **用微信开发者工具导入并上传**
   - 打开微信开发者工具 → 导入项目 → 选择本 `miniprogram` 目录 → 填入你的小程序 AppID；
   - 预览确认后，点「上传」→ 在公众平台提交审核、发布。

## 注意事项

- `web-view` 要求小程序为企业/个体户主体，且网页域名必须配置为业务域名（需 ICP 备案的域名更稳）。
- 如果你暂时没有域名或主体，可以先在微信里直接打开网页链接使用（点右上角收藏 / 添加到浮窗），无需小程序。
- 网页内的数据接口（天天基金、东财、腾讯行情）为 HTTPS，微信 `web-view` 中正常可用。
