# 基金分析器（H5 + 安卓 App）

一个**纯前端**的基金分析工具：不需要服务器，可以在浏览器打开，也可以安装成安卓 App。默认不预置任何基金，全部按你的需求添加，并可按主题 / 市场 / 地区分组。

## 怎么用

### 在线访问（无需安装）
已部署到 GitHub Pages，HTTPS 全网可访问：
**https://codelxw.github.io/fund-analyzer/**

iPhone / 安卓手机用浏览器打开该网址，即可直接使用；iPhone 在 Safari 里点"分享 → 添加到主屏幕"，安卓在 Chrome 里点"添加到主屏幕"，就能像 App 一样全屏使用。

### 安卓手机（推荐）
把根目录下的 `基金分析器-v1.1.apk` 传到手机（微信、QQ、数据线都行），点击安装；首次安装需要在系统提示中允许"安装未知来源应用"。安装后桌面上会显示"基金分析器"图标，打开即可使用，数据自动每日更新。

### 电脑浏览器
直接双击 `index.html`，浏览器打开后会自动从天天基金抓取数据并缓存在本地，之后每次打开都会自动检查更新（缓存 8 小时；手机端在页面顶部**下拉**即可手动刷新，电脑端在"我的"页点"立即刷新全部"）。

### 其他手机（非安卓）
把本文件夹里的文件（`index.html`、`app.js`、`style.css`、`funds.js`、`vendor/`）传到任意静态托管平台（GitHub Pages、Gitee Pages、坚果云网页版等），在手机浏览器打开网址；也可以在微信里把网页"发送到桌面"当 App 用。

> 提示：持仓明细与行情预估接口对手机端支持最好。电脑浏览器打开时，净值、业绩、排名、经理、资产配置都正常；持仓表格若提示受限，用手机（或安卓 App）打开即可看到完整数据。

## 功能

- **看板**：顶部"全球主要指数"实时行情条（上证、深证、创业板、科创50、纳斯达克、日经225、韩国KOSPI、纳斯达克期货，10 秒自动更新）；**下拉页面即可手动刷新全部数据**；"当日更新状态"卡片在指数条下方；区间按钮（全部 / 明日涨幅预估 / 近1周…）下方是"区间涨幅排行"柱状图；另有近 1 周 / 近 1 月 / 近 3 月 / 近半年 / 近 1 年 / 今年来涨幅排行，支持升/降序切换、领涨领跌速览、迷你走势图、同类排名与同类均值对比；每条显示"已更新 / 待更新"状态，待更新的基金会给出**明日涨幅预估**（基于上季持仓 + 最新行情，仅供参考），选中"明日涨幅预估"时，涨幅排行卡片标题变为"明日涨幅预估排序"；预估仅在"基金净值日之后市场已发生交易"时显示（A股当天已更新则不再显示预估）。
- **当日更新状态卡片**：与涨幅排行分开，**跟随看板分组过滤**，顶部标签显示"已更新（N）/ 未更新（M）"数量；点开"已更新"分组，展开任一行可看基金情况（当日涨幅、净值、同类排名、近1周~近1年收益）；"未更新"分组展开可看收益情况（明日涨幅预估、同类排名、同类均值、近1周~近1年收益）。展开状态在 10 秒自动刷新时保持不收起。
- **趋势**：支持**按分组筛选**（全部 / 自定义分组），点开分组只看该组基金，可多选对比；区间累计涨幅对比曲线（横坐标 = 日期，纵坐标 = 累计涨幅 %，以区间首日为 0%，图下有说明）；曲线颜色与上方基金按钮上的彩色圆点一一对应，基金再多也不会遮挡纵坐标标签；相关性热力图解释"红色 = 同步、绿色 = 背离、数字 = 相关系数"，只对比你勾选的基金；**持仓拟合度**卡片展示每只基金近一月每日收益与上季披露持仓模拟组合的相关性（≥60% 拟合良好 / 40%~60% 部分偏离 / <40% 疑似调仓），并可看“基金 vs 持仓模拟组合”近一月累计收益对比曲线，数据随预估每 1 分钟更新。
- **持仓**：支持**按分组筛选**（全部 / 自定义分组）；最新季度前十大重仓股，表格含**当日涨跌（实时行情，10 秒更新）**、占净值比、较上季度增持 / 减持 / 新进明细，另有前十大集中度、**市场分布饼图（美股/港股/…）**、**行业分布饼图**、股票/债券/现金资产配置趋势；**点击任意股票可查看该股实时行情**（最新价、涨跌幅、昨收/今开/最高/最低、近 12 个交易日走势）；上一季度快照自动留档，之后每季度可对比重叠率与退出名单。
- **基金详情（看板点任意基金）**：打开即可看到基金经理信息（姓名、从业年限、管理规模、星级），另有四个页签——业绩（区间表现 + **长期表现：近2/3/5年、成立以来、成立以来年化** + 同类排名百分位趋势 + 本基金 vs 同类平均 vs 沪深300 累计收益曲线 + 股票仓位历史 + 持有人结构 + **近12个月月度收益** + **回撤走势** + **近期统计：上涨天数占比 / 平均日涨幅 / 最大连续涨跌** + 指标解读）、走势、持仓、经理（能力评分雷达图 + 区间表现对比 + 投资风格摘要）。
- **应用设置（"我的"页）**：主题支持"自动（跟随系统）" / 夜间 / 白天——选"自动"后跟随手机系统的浅色/深色设置（夜间或暗光下手机通常自动切深色），系统切换时 App 实时跟随；即时生效并自动保存，图表配色同步跟随。
- **添加 / 我的**：在"我的"页按名称 / 6 位代码搜索添加任意基金；每只基金右侧的"分组"框可**输入任意名称创建自定义分组**（如"美股科技""我的定投"），看板按分组筛选；可移除、一键刷新、清空本地缓存。

初始不预置任何基金，全部由你在"我的"页按名称 / 6 位代码自行添加；分组完全自定义（在每只基金右侧的分组框输入任意名称即可创建），改动保存在浏览器本地。

## 数据说明

- 数据来源：天天基金公开接口（净值历史、区间涨幅、同类排名、季度持仓、资产配置、基金经理信息），指数行情与个股 K 线来自东方财富 / 腾讯行情接口。
- 更新频率：打开页面后每 10 秒自动刷新行情预估，每 60 秒检查基金公司是否公布最新净值（有更新才拉取完整数据），每 30 分钟做一次完整刷新；QDII 基金净值通常比海外市场晚 1 个交易日，因此看板上会区分"已更新 / 待更新"。
- 说明：10 秒级刷新只请求轻量行情与估算数据，不会频繁下载全部净值历史；App 切到后台时，安卓系统会暂停网页定时器以省电，回到前台会立即补一次刷新。
- 预估逻辑：从基金最新净值日到各市场最新收盘日，按前十大持仓权重 × 各股**累计涨跌幅**加权估算（A股 / 港股 / 美股各自按交易日对齐，符合 QDII“前一日 A股 + 晚间美股”的净值构成）；并结合近一月基金收益与披露持仓的拟合度推断是否调仓。**A股（T+1）显示“预计今日涨跌幅”，当天未开盘不显示；QDII 显示“明日涨幅预估”**。每 1 分钟自动重新估算，仅供快速参考，不构成投资建议。
- 所有数据缓存在浏览器本地（localStorage），不会上传你的任何数据。
- 本工具仅用于个人研究与信息展示，不构成投资建议。

## 安卓 App 打包说明

`android/` 目录是安卓壳工程（WebView 包装）。打包环境已就绪（Java 17 + Android Build-Tools 35，装在系统临时工具目录），以后更新网页代码后，运行：

```
powershell -ExecutionPolicy Bypass -File android\build.ps1
```

即可在项目根目录重新生成 `基金分析器-v1.1.apk`（自动使用 `android/icon-source.png` 生成各尺寸图标，沿用同一签名证书，可直接覆盖安装）。
